# Igor Soares — Advogado

Site institucional responsivo para Igor Soares, advogado inscrito na OAB/MG 226.978, com endereço profissional em São João del-Rei, Minas Gerais.

## Tecnologias

- Next.js 16 com App Router
- React 19 e TypeScript
- Tailwind CSS 4
- Framer Motion
- Imagens locais otimizadas pelo Next.js

## Desenvolvimento

```bash
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000) no navegador.
